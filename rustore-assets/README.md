# Изображения для RuStore

`screenshots/` содержит семь вертикальных PNG 1080 × 1920 в порядке публикации. Они показывают текущий интерфейс приложения на вымышленных тренировках и результатах. `icon-512.png` — иконка карточки приложения.

`whats-new-2026-10-02.txt` содержит краткий текст для поля «Что нового» и подробный список изменений этой версии.

Для повторной съёмки запусти локальный сервер командой `npm run dev`, затем в другом терминале выполни `node scripts/render-store-screens.mjs`. Скрипт использует локальный Google Chrome и заменяет изображения в `screenshots/`. Данные пользователя и резервные копии не используются.

Перед загрузкой в RuStore проверь изображения после возможных изменений интерфейса. Предел магазина для телефонного скриншота — 3 МБ; текущие файлы меньше 1 МБ каждый.
