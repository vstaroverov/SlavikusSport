# Согласованные правила интерфейсов · 2.3.0

Зафиксировано 23 сентября 2026 по замечаниям владельца V-STAR-ai-gen-content.
Этот документ имеет приоритет над более ранними примерами при разработке этого
продукта. Общие правила оформления применяются к новым продуктовым экранам;
названия разделов и бизнес-сценарии ниже относятся именно к ai-gen-content.

## Обязательные правила работы

- Делать только запрошенное. Дополнительные блоки, тексты, поля, действия и
  изменения оформления сначала согласовывать с владельцем.
- Минимализм: показывать согласованные данные и действия. Не заполнять свободное
  место слоганами, справками о будущих функциях или техническими пояснениями.
- Использовать существующие HTML/CSS-компоненты и токены V-STAR-GROUP.
  Новые React-компоненты самой дизайн-системы не добавлять. Существующие оставлены
  для совместимости; приложение может использовать свой React для поведения.
- Не переносить оформление и обёртки «Ритма». Название продукта —
  V-STAR-ai-gen-content. Новые экраны не должны наследовать старые белые панели.
- Не подставлять вымышленные пользователей, каналы, суммы и историю операций.
  Отсутствующее значение — прочерк; отсутствие записей и ошибка загрузки — разные
  состояния. Не показывать фиктивное успешное действие.
- Сохранять функционал, проверку прав, подтверждение удаления и защиту
  несохранённых изменений. Убирать лишние пояснения, а не сообщения об ошибках.

## Тема и компоненты

В продукте используется **только тёмная тема**, без переключателя темы.
Тёмной должна быть вся область страницы, включая родительскую обёртку, поля,
таблицы, раскрывающиеся блоки и диалоги, рендерящиеся через portal.
Исторические light-токены в библиотеке оставлены для совместимости старых
каталогов, но не являются разрешённой темой ai-gen-content.

- Фон `--vsg-bg` (#061014), поверхность `--vsg-surface` (#0d2028).
- Основной текст `--vsg-text`, второстепенный `--vsg-muted`, акцент
  `--vsg-primary` (#d8ff18). Шрифт — локальный Manrope.
- Контейнеры `vsg-stack`, `vsg-row`, `vsg-grid`; блоки `vsg-card`;
  кнопки `vsg-button`; поля `vsg-field` / `vsg-input`;
  таблицы `vsg-table-wrap`; история `vsg-accordion`; окна `vsg-dialog`.
- Кнопки в заголовке справа, на одной линии с названием блока; на узком экране
  группа переносится целиком. В карточках одинаковые внутренние отступы.
- У select отступ справа от стрелки равен отступу слева от текста:
  14 px в обычном поле, 12 px в компактном переключателе языка экрана входа.
  Нативную стрелку при необходимости заменить; клавиатурное управление и
  доступное название select сохранить.
- Добавление ссылки не должно менять цвет или размеры подписи. Состояния
  hover/visited/active должны сохранять согласованный цвет; focus остаётся видимым.

## Экран входа

Над формой сохранена строка **V-STAR-ai-gen-content / рабочее пространство**
с иконкой замка слева. Не показывать «С возвращением», «Введите пароль владельца,
чтобы продолжить работу» и «Доступ только для владельца пространства».
Поля логина/пароля, переключатель видимости пароля и действие входа сохраняются.

Подпись «V-STAR-ai-gen-content — продукт V-STAR Group» — ссылка на
https://v-star-group.ru, новая вкладка, `rel="noopener noreferrer"`.
На странице входа ссылка белая (#ffffff), в том числе после посещения и при
наведении. В общем футере других страниц ссылка наследует уже согласованный цвет.

Favicon: лаймовая V со звездой на тёмном фоне. Утверждённый продуктовый образец —
[assets/v-star-ai-gen-content-favicon.png](assets/v-star-ai-gen-content-favicon.png).
Это знак продукта, не замена корпоративного логотипа группы.

## Общий каркас

- Слева не показывать блок «РАБОЧЕЕ ПРОСТРАНСТВО», название сообщества и его аватар.
- Убрать нижний блок «VK настроен / Автопубликация доступна» и его альтернативы.
- Над «РАЗДЕЛЫ» — 24 px верхнего отступа в текущем каркасе ai-gen-content.
- Раздел «Персонаж» убран из левого меню; в меню профиля справа он называется
  «Аватар» и расположен перед «Настройками». Выход остаётся там же.
- Имя пользователя и выбранный язык приходят с сервера в первом HTML. Не
  показывать «Владелец» с последующей заменой логином. Не делать RU сначала
  полупрозрачным, а после загрузки салатовым. При недоступных данных не выдумывать
  личность; загрузка/ошибка не должна изменять геометрию хедера.
- Не менять права доступа на основе UI: серверные проверки обязательны.

## Настройки: только три блока

### Общая информация

Логин текущего пользователя и язык интерфейса. По умолчанию русский;
согласованные варианты RU / ENG. Логин показывается из данных пользователя.

### Баланс

Три показателя: «Доступный баланс», «Зарезервировано»,
«Расход в текущем месяце». Единица — V-Token; отдельной плашки «V-Token» в
заголовке нет. Справа кнопка «Пополнить». До подключения платежей она неактивна,
не создаёт начисления и не имитирует оплату.

«История операций» раскрывается; колонки: Дата, Операция (списание/пополнение),
Назначение, Сумма, Статус. Реальные данные подключаются отдельной задачей;
макет или наличие кнопки не означают готовый биллинг.

### Подключённые каналы

Кнопка добавления и таблица каналов с редактированием, удалением и проверкой
соединения. Нет поиска, фильтра и кнопки обновления — их не заказывали.
При пустом списке вместо таблицы только состояние:

**Добавьте первый канал**

Выберите социальную сеть, укажите ссылку и параметры подключения.

Форма сохраняет согласованные поля: площадка, имя, ссылка, ID назначения,
Secret API, часовой пояс. Секрет можно заменить/удалить, но нельзя получить
обратно из API. Для неподдерживаемой площадки не имитировать проверку соединения.

Для полей «Социальная сеть» и «Часовой пояс» использовать `vsg-select`:
отступ справа от стрелки и отступ слева от текста — по 14 px. Выбор остаётся
нативным, с доступным названием и управлением с клавиатуры.

При выборе ВКонтакте справа от названия поля ID сообщества показывать значок
восклицания с подсказкой «Откройте любой пост сообщества, ID будет в ссылке
сверху». Для поля Secret API — подсказку «В сообществе справа Управление ->
Дополнительно -> Работа с API». Использовать `vsg-field-heading`,
`vsg-field-help` и `vsg-tooltip`: подсказка появляется при наведении и фокусе,
доступна с клавиатуры. Для других площадок эти VK-подсказки не показывать.

Часовые пояса берутся из отдельной таблицы, в выборе один основной пояс на
каждое смещение РФ: Калининград +2, Москва +3, Самара +4, Екатеринбург +5,
Омск +6, Красноярск +7, Иркутск +8, Якутск +9, Владивосток +10,
Магадан +11, Камчатка +12. Москва первая и по умолчанию. Сохранённые ранее
значения не перезаписывать молча. Полный мировой список в форме не показывать.

У страницы нет старой контекстной панели автоматизации, слогана «КОНТЕНТ В ТВОЁМ
РИТМЕ», описания кабинета и лишних блоков о будущих уведомлениях.

## Админка

Только для роли «Владелец». Пункт слева раскрывается, при первой загрузке свёрнут.
Подпункты: **API-подключения**, **Пользователи**, **Статистика**, **Логи и журнал**.
Каждый открывает отдельный экран в общей оболочке приложения; дублирующих
горизонтальных вкладок нет. При смене экрана сохраняется проверка несохранённых
изменений. Сворачивание меню само по себе не меняет открытый экран.

Оформление как у Настроек: тёмная область и компоненты дизайн-системы, без старой
контекстной панели и декоративных вступительных текстов. Состав действий и
таблиц определяется согласованной спецификацией раздела, а не дизайнером.

## Проверка перед сдачей

1. Нет белой родительской области вокруг тёмных блоков или светлого portal.
2. На первой загрузке не меняются логин, язык, цвет или ширина контролов.
3. Изменено только запрошенное; дополнительные решения согласованы.
4. Кнопки, фокус, клавиатура, модальные окна и защита изменений работают.
5. Нет вымышленных данных; сообщения пустого списка и ошибки различаются.
6. Проверены RU/ENG, узкий экран и длинные реальные названия.
7. Указано, что проверено автоматически и что реально осмотрено в браузере.
