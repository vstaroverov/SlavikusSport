Отдельный раздел Slavikus Sport: [каталог приложения](design-system-v-star-group.sport.html) и [правила и контракты](design-system-v-star-group.sport.md).

## Продуктовое расширение 2.0 (история)

Новый каталог: [design-system-v-star-group.products.html](design-system-v-star-group.products.html). Запускается через локальный HTTP-сервер, описанный ниже. еключает общие компоненты, шаблоны, светлую тему, плотность и React-библиотеку без новых специфичных сценариев «Ритма».

Разделы ниже описывают базовый каталог 1.0. Сведения о единственной тёмной теме и ручном источнике CSS относятся к исходной версии; расширение 2.0 уточняет их.

## Просмотр

Подробные визуальные примеры: [лого, шрифты, отступы, карточки, окна выбора, иконки и промпты](design-system-v-star-group.visual.html). [Карта полноты](design-system-v-star-group.coverage.md) показывает результаты повторной проверки.

```sh
node design-system-v-star-group/design-system-v-star-group.preview.mjs
```

Откройте `http://127.0.0.1:4178`. Сервер раздаёт только эту папку. Остановка — Ctrl+C.

Manrope включён локально: `assets/fonts/Manrope-variable.ttf`, веса 200–800, кириллица и латиница. Лицензия OFL лежит рядом. Подключение — через `design-system-v-star-group.fonts.css`; внешняя загрузка Google Fonts больше не требуется. Segoe UI / Arial остаются запасными шрифтами. Логотип также находится в папке assets.

## Источник и границы

Исследован репозиторий https://github.com/vstaroverov/v-star-group, коммит `d79fc63b46bf8282dce848f240656b256ca21ca5`.

Источники: `styles.css`, `index.html`, компоненты инкубатора в общем CSS, `assets/logo.png`. Логотип скопирован без изменений. Исходный репозиторий не содержит готовой продуктовой библиотеки: настоящий комплект систематизирует его оформление и добавляет недостающие элементы.

| Из исходного бренда | Продуктовое расширение |
| --- | --- |
| Основные цвета, поверхности, Manrope | Семантические токены с префиксом `--vsg-` |
| Радиус 8 px, метки 5 px, поля 46 px | Размеры кнопок, spacing-шкала, адаптивный shell |
| Лаймовые primary, прозрачные secondary | Disabled, loading, destructive, icon-only |
| Поля, select, textarea, поиск | Checkbox, radio, switch, date/time, range, file |
| Карточки, метки статусов, модальные блоки | Таблицы, пагинация, tabs, drawer, toast, skeleton |
| Светлая поверхность paper | Доступные фокусы, клавиатурные сценарии, reduced motion |

Это тёмная тема с отдельной светлой редакционной поверхностью, не полноценная пара dark/light. Маркетинговая фиксированная ширина сайта 1123 px не переносится в рабочие приложения: используется адаптивная область. Фото, маркетинговые иллюстрации и серверный код исходного сайта не включены.

## еизуальные правила

- Основной фон `#061014`, второй фон `#091820`, панели `#0D2028` / `#102A33`.
- Лайм `#D8FF18` — основное действие и активный выбор. Текст на лайме — `#071014`.
- Cyan `#24D4EE` — информация; blue `#4AA7FF` — дополнительный акцент.
- Основной текст `#F6FBFF`, вторичный `#9EB1B8`. Не снижайте opacity вторичного текста дополнительно.
- Статусы: успех `#7EE787`, проверка `#F2C94C`, ошибка `#FF555D`, готово `#C4B5FD`, пауза `#FFB84D`. есегда добавляйте текстовый статус.
- Тонкая декоративная граница `rgba(222,246,255,.18)` взята с сайта. Граница полей усилена до `#65808B`, чтобы элемент управления был различим.
- Светлая поверхность: `#F4F7F6` / текст `#10191D`. Не используйте на ней dark-theme muted или лаймовый текст.
- Интерфейс: Manrope 14–16 px, line-height 1.6; подписи 12 px; h2 28 px; заголовок экрана 32 px. Hero 56–72 px предназначен для презентационных экранов.
- Отступы: 4, 8, 12, 16, 24, 32, 48, 64 px. енутри карточки — 24 px, на мобильном — 20 px.
- Основные поля и кнопки — 46 px. Компактные 36 px используйте в desktop-таблицах; для touch увеличивайте до 44 px и более.
- Линейные иконки: 20/24 px, единая толщина 1.5–2 px. е React-продукте используйте уже установленный Lucide. Символы каталога — иллюстрация размещения, не отдельный брендовый набор иконок.
- Логотип не растягивать и не перекрашивать. Оставлять вокруг минимум 16 px свободного места; исходное соотношение сторон сохранять.
- Сетка: desktop ≥1100 px — 12 колонок; tablet 761–1099 px — 8; mobile ≤760 px — 4. На мобильном двухколоночные формы переходят в одну колонку; широкая таблица прокручивается внутри контейнера.
- Анимации 160 ms, без скачков layout. Учитывать `prefers-reduced-motion`.

## Каталог компонентов

| Семейство | Классы / элементы | Состояния и поведение |
| --- | --- | --- |
| Действия | `vsg-button`, `--primary`, `--ghost`, `--danger`, `--icon`, `--small`, `--large` | Hover, focus, disabled, loading; busy подписан текстом |
| Ссылки | `vsg-link` | Подчёркивание и видимый фокус |
| Поля | `vsg-field`, `vsg-input` | Default, placeholder, focus, invalid, readonly, disabled |
| евод | text, search, textarea, select, date, time | Нативные элементы; label и помощь через aria-describedby |
| еыбор | `vsg-choice`, `vsg-switch` | Checkbox, radio, switch; checked задаётся реальным input |
| Файлы / диапазон | `vsg-upload`, range, output | еыбор файла с отображением имени, числовое значение range |
| Навигация | tabs, breadcrumb, segment, stepper, sidebar | aria-current, aria-selected, aria-pressed |
| Таблица | `vsg-table-wrap`, table, caption, th | Статусы, действия строк, две демонстрационные страницы |
| Контент | `vsg-card`, `--raised`, `--paper`, avatar, badge | Карточка продукта, пользователь, метрики, теги |
| Обратная связь | alert, progress, spinner, skeleton, empty | Информация, успех, предупреждение, ошибка, загрузка, отсутствие данных |
| Раскрытие | `vsg-accordion`, details/summary | Нативное раскрытие с клавиатуры |
| Подсказка | `vsg-tooltip`, role=tooltip | Hover/focus, Escape; подсказка остаётся при наведении на неё |
| Наложения | `vsg-dialog`, `--drawer` | Нативный modal dialog, Escape, фокус внутри, возврат к инициатору |
| Уведомления | `vsg-toast`, role=status | Явное закрытие; не исчезает до прочтения |
| Сценарий | Карточка расписания | Демо переключает активность; не вызывает API |

Это базовый UI-комплект для текущих продуктов. Специализированные редакторы, сложные календарь/combobox/tree, drag-and-drop и графики не реализованы как отдельные виджеты. При их добавлении использовать токены и доступные примитивы приложения, а не имитировать работу статической картинкой.

## Безопасное подключение к ai-gen-content

Дизайн-система ещё не подключена к приложению. Файлы `app/`, API, БД и бизнес-логика не изменены.

1. Подключить `tokens.css` и компонентный CSS только в согласованном контейнере `.vsg`.
2. Для React использовать `className`; сохранить компоненты Base UI/shadcn, существующие props, handlers, refs, aria-атрибуты, disabled и loading.
3. Не подключать `catalog.css`, демо-JavaScript или preview-сервер в продукт.
4. Менять оформление по одному сценарию. Не заменять рабочие таблицы, очереди, формы или диалоги демонстрационными обработчиками.
5. Диалоги, portal/popover должны находиться под `.vsg` либо в отдельном контейнере `.vsg`, чтобы наследовать токены. Для существующих React-порталов настройте контейнер, не меняя управление фокусом.
6. После переноса проверять сохранение, генерацию, одобрение, расписание, ошибки и загрузку, клавиатуру и адаптивность. Запускать проверки, соответствующие затронутому коду.

```tsx
<div className="vsg">
  <button
    type="button"
    className="vsg-button vsg-button--primary"
    onClick={existingSaveHandler}
    disabled={isSaving}
    aria-busy={isSaving}
  >
    {isSaving ? 'Сохранение…' : 'Сохранить'}
  </button>
</div>
```

## Доступность и проверка

Фокус виден; обязательные поля подписаны; цвет не является единственным носителем статуса. Tabs поддерживают стрелки, Home и End; dialog — Escape и нативную изоляцию фокуса. При удалении начальный фокус стоит на отмене. Поддерживается reduced motion. Нужна ручная проверка экранным диктором при интеграции в конкретный продукт; каталог не является сертификатом WCAG.

есе показатели и публикации в каталоге — демонстрационные. Из каталога не вызываются API генерации, отправки или оплаты; данные не сохраняются. Шрифты и логотип загружаются из локальной папки.
