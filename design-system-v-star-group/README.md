Базовый и визуальный каталоги можно открыть как локальные HTML-файлы. Для всех каталогов, включая продуктовые ES-модули, из корня репозитория:

```sh
node design-system-v-star-group/design-system-v-star-group.preview.mjs
```

Затем открыть `http://127.0.0.1:4178`. Шрифт Manrope и логотип включены локально. Каталоги демонстрационные: не вызывают API продукта и не публикуют данные.

## Как обновлять

1. Изменить `VERSION`: patch для исправлений, minor для совместимых дополнений, major для несовместимых изменений.
2. Добавить описание новой версии в начало changelog, сохранив историю.
3. Обновить видимые номера в HTML, текущую версию в документации и `version` в `design-system-v-star-group.tokens.source.json`.
4. Выполнить `node design-system-v-star-group/design-system-v-star-group.build-tokens.mjs` для синхронизации JSON-токенов.
5. Проверить HTML, ресурсы, работу примеров и затем загрузить обновлённую папку в этот репозиторий.

При сравнении копий ориентироваться на `VERSION`, затем на commit Git. Не считать дату файла номером версии.

## Статус и состав

Включены HTML/CSS/JS-каталоги, локальные ресурсы, токены и документация. Ранее созданные React-файлы оставлены как дополнительный материал; для просмотра каталогов они не нужны. Локальные TypeScript/SSR-проверки из исходного проекта ссылаются на соседнюю папку `app/node_modules`: в репозитории сайта этой среды может не быть. Preview и генератор токенов требуют только Node.js.

Синтаксис, ссылки и основные автоматические проверки выполнены. Полная визуальная проверка desktop/mobile в браузере остаётся открытой. Подключение дизайн-системы к рабочему сайту автоматически не выполняется.
